# agents-memo — session init

This session has an Obsidian vault configured by the `agents-memo` plugin. The vault is a knowledge base, not a code directory.

## When to engage the vault

- The user plans or brainstorms → `/memo-query` the vault for context.
- The user asks a question that prior notes might answer → `/memo-query`.
- The user wants to file something for later → `/memo-note`, `/memo-daily`, `/memo-save`.
- The user mentions vault / wiki / notes / daily / ingest / research / lint / canvas.

## When NOT to engage the vault

Straightforward coding questions — common knowledge or answerable by reading the
code. Do not re-derive what the code already tells you; the wiki holds
synthesized knowledge: decisions, architectural quirks, and complex concepts.

## Vault I/O

Read `${MEMO_PLUGIN_PWD}/skills/vault-ops/SKILL.md` first, then follow its instructions.
